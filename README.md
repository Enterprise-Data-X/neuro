## Core Purpose

The primary goal of Neuro is to eliminate **architectural drift** and **compliance gaps** when using AI for software development.

| Challenge | Solution |
|-----------|----------|
| Inconsistent code generation | Strict architectural templates |
| Compliance violations | Policy-First approach |
| Security gaps | Automatic policy enforcement |
| Audit trail missing | Centralized logging |

---

## Key Features

### ✓ Policy-Driven Code Generation
- **Policy Inheritance**: Every skill generated by Neuro is filtered through active policies (Security, Performance, Data Privacy)
- **Compliance by Design**: Generated code automatically includes necessary headers, authentication middleware, and logging
- **Pre-Compiler Checks**: Policies act as validation before code execution

### ✓ Template Considered API Service Ready by Neuro AI
- **Consistency**: Every endpoint, model, and controller follows your organization's template architecture
- **Accuracy**: Maps Swagger/OpenAPI definitions to structured code logic
- **Policy Constraints**: All generation respects active compliance policies

### ✓ AI-Powered generation Batch Services
- **Standardization**: All batch jobs follow the same execution and monitoring patterns
- **Resilience**: Automatic retry logic and circuit breaker patterns applied via policies

## Use Cases

### 1. Policy-Driven Skill & Code Generation
Generate new skills that automatically comply with organizational standards:
```bash
neuro start
# Within the console:
/policy list                      # View active organizational policies
/policy add security_v1.json      # Apply a new security policy
/skills apply my_skill --policy security_v1
```

### 2. Template-Driven API Generation
Convert Swagger/OpenAPI specs into fully compliant API services:
```bash
/skills apply swagger_to_api --input ./swagger.json --policy security_v1
```

### 3. Batch Service Creation
Generate batch processing services with built-in compliance and resilience:
```bash
/skills apply batch_service --input ./config.json
```

## System Architecture

Neuro maintains a localized workspace for isolation and security.

```
~/.neuro/                    # Neuro workspace root
├── policies/                # Organizational rules & compliance standards
├── scripts/                 # Transformation logic for code generation
├── skills/                  # Foundation skills blueprints
├── log/                     # Audit logs for all operations
│   └── neuro.log
└── config.json              # Source of truth for commands & policies
```

### Installation Paths

- **Binary**: `/usr/local/bin/neuro`
- **Workspace**: `~/.neuro`

## Installation

### Requirements
- Python 3.10+
- pip or virtual environment manager

### Setup
```bash
# Clone or download neuro-installer
cd neuro-installer

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install in editable mode
pip install -e .

# Verify installation
neuro start
```

## Commands Reference

### Core Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `/status` | Check Neuro environment health | `/status` |
| `/config` | Manage environment variables and paths | `/config logging true` |
| `/help` | Display available commands | `/help` |
| `/exit` | Exit the TUI | `/exit` |

### Policy Management

| Command | Purpose |
|---------|---------|
| `/policy list` | View active organizational policies |
| `/policy add <file>` | Apply a new compliance policy |
| `/policy remove <name>` | Deactivate a policy |

### Skills & Generation

| Command | Purpose |
|---------|---------|
| `/skills` | List available generation blueprints |
| `/skills apply <name>` | Execute a skill with optional parameters |
| `/skills apply swagger_to_api --input ./swagger.json` | Generate API from Swagger spec |

### Agent Management

| Command | Purpose |
|---------|---------|
| `/agent list` | View configured AI agents |
| `/agent add api-key <key>` | Register an API key for an agent |

### Utilities

| Command | Purpose |
|---------|---------|
| `/bash <command>` | Execute shell commands directly |
| `/clear` | Clear operation logs |

## Security & Privacy

### Core Principles

✓ **Private Infrastructure**: Neuro operates entirely within your environment  
✓ **Policy Governance**: All AI interactions governed by internal policy definitions  
✓ **No Code Leaks**: Business logic and policies never leave the local environment  
✓ **Full Audit Trail**: All operations logged in `~/.neuro/log/neuro.log`

### Best Practices

1. **Regularly review logs** for unauthorized policy changes
2. **Version control** your policy files
3. **Rotate API keys** periodically
4. **Backup** your `~/.neuro` directory

## Troubleshooting

### Neuro won't start
- Check Python 3.10+ is installed: `python3 --version`
- Verify virtual environment: `source .venv/bin/activate`
- Reinstall: `pip install -e .`

### Commands not recognized
- List available commands: `/help`
- Check config: `/config`
- Review logs: `tail -f ~/.neuro/log/neuro.log`

### Policy not applying
- Verify policy file exists in `~/.neuro/policies`
- Check policy syntax: `/policy list`
- Review logs for validation errors
